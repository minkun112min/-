# 아이패드로 마트 특가 자동 수집하기 (Scriptable)

pabal 마트 2곳(gjs, ogq)은 해외 서버 접속을 막아서, **한국에 있는 아이패드**가 대신 페이지를 받아 GitHub에 올립니다.
올라가면 GitHub이 1~2분 안에 자동으로 특가를 정리해 앱에 반영합니다.

```
[아이패드 Scriptable] 매일 아침 마트 페이지 받기 → GitHub inbox 폴더에 올리기
        ↓
[GitHub] 페이지에서 품목·가격 읽기 → data/sales.json 저장 → 앱에 표시
```

준비물: 아이패드(와이파이 연결, 켜 둔 상태), GitHub 로그인, 15분

---

## 1단계. GitHub 열쇠(토큰) 만들기 — 사파리에서

단축어가 이 저장소에 파일을 올릴 수 있게 해 주는 열쇠입니다. **이 저장소에만, 파일 올리기만** 허락합니다.

1. 사파리에서 열기: **https://github.com/settings/personal-access-tokens/new**
2. **Token name**: `민식당 단축어`
3. **Expiration**: `Custom` → 1년 뒤 날짜 (만료되면 이 단계만 다시 하면 됩니다)
4. **Repository access**: `Only select repositories` → `minkun112min/-` 선택
5. **Permissions** → **Repository permissions** → **Contents** 를 `Read and write` 로
6. 맨 아래 **Generate token** → 나온 `github_pat_...` 글자를 **복사** (이 화면을 닫으면 다시 볼 수 없어요)

> 이 열쇠는 비밀번호와 같아요. 단축어 안에만 넣고, 카톡 등으로 보내지 마세요.
> 단축어 화면을 캡처해 보낼 때도 토큰이 보이면 가려 주세요. 노출됐다면 위 주소에서 **Delete** 후 새로 만드세요.

---

## 2단계. Scriptable 앱에 코드 붙여넣기 (한 번만)

> 예전 방식(단축어 동작을 하나씩 만들기)은 쓰지 않습니다. 만들던 단축어는 지워도 됩니다.

1. App Store 에서 **Scriptable** (무료, 개발자 Simon Støvring) 설치
2. Scriptable 열기 → 오른쪽 위 **+** → 빈 화면이 나옴
3. 사파리에서 아래 주소를 열고 코드 전체를 길게 눌러 **복사**
   **https://github.com/minkun112min/-/blob/main/ipad/loader.js**
   (main 에 합치기 전이면: `https://github.com/minkun112min/-/blob/claude/mart-sale-automation-ydx056/ipad/loader.js`
   → 오른쪽 위 **Raw** 버튼을 누르면 코드만 보여 복사하기 쉬움)
4. Scriptable 빈 화면에 **붙여넣기** → 위쪽 제목(Untitled Script)을 눌러 이름을 `민식당 수집` 으로 → **Done**
5. 목록에서 **민식당 수집** 을 눌러 실행 → 토큰 입력 창이 뜨면 1단계 토큰 붙여넣기 → 저장
6. 잠시 뒤 `gjs ✅ · ogq ✅` 가 뜨면 성공

- 토큰은 아이패드 키체인에 저장돼 화면에 다시 보이지 않습니다.
- 수집 코드는 실행할 때마다 GitHub 에서 최신본을 받아 옵니다. **고칠 게 생겨도 아이패드에서는 다시 붙여넣을 필요가 없습니다.**
- 실행 기록은 GitHub `ipad/last-run.txt` 에 남아 Claude 가 원인을 바로 확인할 수 있습니다.
- 토큰이 틀렸거나 만료되면 다음 실행 때 토큰을 다시 물어봅니다.

---

## 3단계. 매일 아침 자동 실행

단축어 앱 → 아래 **자동화** 탭 → **+** (새로운 자동화)

1. **특정 시간** 선택 → 시간 `오전 6:50`, 반복 **매일**
2. **즉시 실행** 선택 (확인 질문 없이 실행)
3. 다음 → **새로운 빈 단축어** (또는 동작 추가) → 검색에 `Scriptable` → **Run Script(스크립트 실행)** → Script: **민식당 수집**
4. 완료

아이패드가 **켜져 있고 와이파이에 연결**돼 있으면 잠겨 있어도 실행됩니다. 밤새 충전기에 꽂아 두면 가장 확실합니다.

## (선택) "오늘의 특가"(ezip) 마트 — 사파리 공유 버튼으로 보내기

이 마트 페이지는 "자동등록방지" 화면이 있어 자동으로 받지 않습니다.
사장님이 **사파리에서 직접 연 페이지**를 공유 버튼으로 보내면, Scriptable 이 GitHub 에 올립니다.

### 한 번만 설정
1. **설정** 앱 → **앱** → **단축어** → **고급** → **스크립트 실행 허용** 켜기
2. **단축어** 앱 → **+** → 이름 `특가 보내기`
3. 오른쪽 위 **ⓘ** → **공유 시트에서 보기** 켜기 → 완료
4. 맨 위에 생긴 `공유 시트에서 [ … ] 입력 받기` 의 파란 글자를 눌러 **Safari 웹 페이지** 만 남기기
5. 동작 추가 → 검색 `JavaScript` → **웹 페이지에서 JavaScript 실행**
   - 웹 페이지: 🔵 `단축어 입력`
   - 코드 칸의 내용을 전부 지우고 아래 한 줄 붙여넣기
     `completion(location.href + "\n" + document.documentElement.outerHTML);`
6. 동작 추가 → 검색 `Scriptable` → **Run Script**
   - Script: **민식당 수집**
   - 펼치기(>) → **Parameter**: 🔵 `JavaScript 결과` (5번 결과) · **Run In App**: 끔
7. 동작 추가 → 검색 `알림` → **알림 보기** → 내용: 🔵 `스크립트 결과`(6번 결과)

### 매번 쓰는 법
앱의 바로가기에서 마트 페이지 열기 → (보안 확인 화면이 나오면 OK) → 상품이 보이면 **공유(□↑)** → **특가 보내기**
→ `ezip 특가 페이지를 보냈어요 ✅` 알림이 뜨면 완료.

> 첫 번째로 보낸 페이지는 Claude 가 읽기 규칙을 만드는 데 씁니다. 처음 보낸 뒤 **"체크해줘"** 라고 알려 주세요.
