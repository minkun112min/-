# 아이패드 단축어로 마트 특가 자동 수집하기

pabal 마트 2곳(gjs, ogq)은 해외 서버 접속을 막아서, **한국에 있는 아이패드**가 대신 페이지를 받아 GitHub에 올립니다.
올라가면 GitHub이 1~2분 안에 자동으로 특가를 정리해 앱에 반영합니다.

```
[아이패드 단축어] 매일 아침 마트 페이지 받기 → GitHub inbox 폴더에 올리기
        ↓
[GitHub] 페이지에서 품목·가격 읽기 → data/sales.json 저장 → 앱에 표시
```

준비물: 아이패드(와이파이 연결, 켜 둔 상태), GitHub 로그인, 15분

---

## 1단계. GitHub 열쇠(토큰) 만들기 — 사파리에서

단축어가 이 저장소에 파일을 올릴 수 있게 해 주는 열쇠입니다. **이 저장소에만, 파일 올리기만** 허락합니다.

1. 사파리에서 열기: **https://github.com/settings/personal-access-tokens/new**
2. **Token name**: `민식당 단축어`
3. **Expiration**: `Custom` → 1년 뒤 날짜 (만료되면 이 단계만 다시 하면 됩니다)
4. **Repository access**: `Only select repositories` → `minkun112min/-` 선택
5. **Permissions** → **Repository permissions** → **Contents** 를 `Read and write` 로
6. 맨 아래 **Generate token** → 나온 `github_pat_...` 글자를 **복사** (이 화면을 닫으면 다시 볼 수 없어요)

> 이 열쇠는 비밀번호와 같아요. 단축어 안에만 넣고, 카톡 등으로 보내지 마세요.
> 단축어 화면을 캡처해 보낼 때도 토큰이 보이면 가려 주세요. 노출됐다면 위 주소에서 **Delete** 후 새로 만드세요.

## 2단계. 단축어 만들기: "민식당 특가 수집"

단축어 앱 → 오른쪽 위 **+** → 이름을 `민식당 특가 수집` 으로. 아래 동작을 위에서부터 순서대로 검색해 추가합니다.

| # | 추가할 동작 (검색어) | 설정 |
|---|---|---|
| 1 | **텍스트** | 1단계에서 복사한 `github_pat_...` 붙여넣기 |
| 2 | **변수 설정** | 변수 이름 `토큰`, 입력: 텍스트 |
| 3 | **목록** | 항목 2개: `gjs`, `ogq` (마트 주소의 앞부분) |
| 4 | **각 항목 반복** | 입력: 목록 |
| 5 | **URL의 콘텐츠 가져오기** | URL 칸에 `https://` 🔵`반복 항목` `.pabal.net/main.html` (띄어쓰기 없이, 그대로 GET) |
| 6 | **Base64 인코딩** | 입력: `URL의 콘텐츠` · 줄 바꿈: **없음** |
| 7 | **텍스트** | `https://api.github.com/repos/minkun112min/-/contents/inbox/` `반복 항목` `-` `현재 날짜` `.html`<br>(사이에 띄어쓰기 없이. 아래 "날짜 넣는 법" 참고) |
| 8 | **URL의 콘텐츠 가져오기** | URL: 7번 `텍스트`<br>펼치기(>) → 방법: **PUT**<br>헤더 추가: `Authorization` = `Bearer ` + `토큰` 변수 (Bearer 뒤 한 칸 띄움)<br>헤더 추가: `Accept` = `application/vnd.github+json`<br>요청 본문: **JSON**<br>· 텍스트 `message` = `아이패드 수집`<br>· 텍스트 `content` = `Base64 인코딩됨` 변수<br>· 텍스트 `branch` = `main` |
| 9 | (반복 끝) | 4번에서 자동으로 생긴 "반복 종료" 그대로 |

**7번에 날짜 넣는 법** ("날짜 형식" 동작은 따로 추가하지 않아요)
1. 7번 텍스트 칸에서 `inbox/` 뒤를 누르고, 키보드 위 **변수** 막대에서 `반복 항목` → 이어서 `-` 입력
2. 다시 변수 막대에서 **현재 날짜** 를 눌러 넣기 (안 보이면 **변수 선택** → 현재 날짜)
3. 들어간 파란 `현재 날짜` 를 한 번 누르기 → **날짜 형식: 사용자 지정** → 형식 칸에 `yyyyMMdd-HHmmss`
4. 그 뒤에 `.html` 입력

완성 예: `…/contents/inbox/`🔵반복 항목`-`🔵현재 날짜`.html` → 실제로는 `inbox/gjs-20261027-065012.html`

> 3번에서 "사용자 지정"이 안 보이면: 동작 검색에 **포맷** 이라고 쳐서 **날짜 포맷** 동작을 6번과 7번 사이에 넣고 (날짜: 현재 날짜, 형식: 사용자 지정 `yyyyMMdd-HHmmss`), 7번에서는 `현재 날짜` 대신 그 결과(`포맷된 날짜`)를 넣으세요.

**시험하기:** 오른쪽 아래 ▶ 를 누릅니다. 오류 없이 끝나면 성공!
1~2분 뒤 앱에서 해당 마트에 "오늘 ○○:○○ 수집"이 보이면 완성입니다.

> 앱에 특가가 0개로 나오면 정상입니다. 첫 페이지가 올라오면 Claude에게 "아이패드로 올렸어" 라고 알려 주세요.
> 올라온 원본(`raw/gjs.html`)을 보고 그 마트 전용 읽기 규칙을 맞춰 드립니다.

## 3단계. 매일 아침 자동 실행

단축어 앱 → 아래 **자동화** 탭 → **+** (새로운 자동화)

1. **특정 시간** 선택 → 시간 `오전 6:50`, 반복 **매일**
2. **즉시 실행** 선택 (확인 질문 없이 실행), "실행 시 알림" 은 꺼도 됩니다
3. 다음 → **민식당 특가 수집** 선택 → 완료

아이패드가 **켜져 있고 와이파이에 연결**돼 있으면 잠겨 있어도 실행됩니다. 밤새 충전기에 꽂아 두면 가장 확실합니다.

## (선택) "오늘의 특가"(ezip) 마트 — 사파리에서 공유 버튼으로 보내기

이 마트 페이지는 "자동등록방지" 화면이 있어 자동으로는 받지 않습니다.
대신 **사파리에서 열어 본 뒤 공유 버튼 한 번**으로 보낼 수 있게 합니다.

먼저: **설정 → 앱 → 단축어 → 고급 → "스크립트 실행 허용"** 켜기

새 단축어 `특가 보내기(ezip)`:

| # | 동작 | 설정 |
|---|---|---|
| 1 | (단축어 맨 위 입력 칸) | **공유 시트**에서 받기 → 입력 유형 **Safari 웹 페이지** 만 |
| 2 | **웹 페이지에서 JavaScript 실행** | 웹 페이지: `단축어 입력`<br>내용을 지우고: `completion(document.documentElement.outerHTML);` |
| 3 | **Base64 인코딩** | 줄 바꿈: 없음 |
| 4 | **URL의 콘텐츠 가져오기** | 2단계의 8번과 똑같이, 단 URL 끝을 `inbox/ezip-` `현재 날짜`(사용자 지정 `yyyyMMdd-HHmmss`) `.html` 로,<br>`Authorization` 값은 `Bearer github_pat_...` 직접 입력 |
| 5 | **알림 보기** | `오늘의 특가 보냈어요` |

쓰는 법: 앱의 바로가기에서 ezip 마트 페이지 열기 → 사파리 **공유(□↑)** → **특가 보내기(ezip)**

## 문제가 생기면

| 증상 | 확인할 것 |
|---|---|
| 단축어가 401/403 오류 | 토큰이 만료됐거나 Contents 권한이 빠짐 → 1단계 다시 |
| 422 오류 | 7번 주소에 띄어쓰기가 들어감, 또는 날짜 형식이 빠져 같은 이름이 됨 |
| 404 오류 | 7번 주소 오타 (`minkun112min/-` 확인), 또는 아직 main 에 합쳐지지 않음 |
| 앱에 반영이 안 됨 | GitHub 저장소 → Actions 탭 → "아이패드가 보낸 마트 페이지 정리" 기록 확인 |
